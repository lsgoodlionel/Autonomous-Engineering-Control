# 自治工程 SOP

<!-- harness-delivery-status: not_started -->

## 准入

1. 验证 Git 仓库、独立 worktree、分支、HEAD 和工作区归属。
2. 读取已批准计划，绑定计划 SHA-256、单个 Milestone 和验收标准。
3. 根据 Gate 矩阵与保护路径确定自动范围和人工边界。
4. 需求模糊、缺少测试、没有验收标准或需要高风险操作时暂停。

## 执行

- 测试先行，最小实现，运行实际变更触发的 Gate 并集。
- Gate 使用参数数组，不经 Shell 拼接；未知配置与未匹配路径失败关闭。
- generated 路径先在临时输入树中用策略登记 argv 重跑；输入、输出、写集、工具或超时不满足时暂停。
- 状态写入 `var/agent-harness/runs/`，原始输出不提交。
- 自动修复预算：同一指纹 3 次、总失败周期 5 次、连续无进展 2 轮。

## 人工升级

依赖新增、保护路径、认证授权、数据迁移、生产、Release、秘密处理、架构冲突和无法可靠验证的变更必须暂停，由明确责任人审批。人工决定应记录脱敏摘要，不能用决定记录绕过技术策略。

## 恢复与完成

恢复前重新运行 `doctor` 并核对计划、分支、HEAD、工作区和工具。HEAD 改变后重跑 Gate。只有当前 HEAD 的全部必需 Gate 成功、证据存在、所需复审完成后才能 `finalize`。
